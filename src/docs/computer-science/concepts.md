## Big O Notation

Used to approximate the growth rate of an algorithm in either space or time.

- O(1) - Constant complexity growth
- O(log n) - Big O notation for space and time complexity
- O(n) - Linear complexity growth
- O(n log n) - Big O notation for both space and time complexity
- O(n^2) - Big O notation for space and time complexity
- O(2^n) - Big O notation for space and time complexity
- O(n!) - Big O notation for space and time complexity

## Machine Learning

Teaching a computer to do a task without explicitely specifying how to do it.

Requires training data test data. Then choose an algorithm that can change its
parameters over time, such as a neural network.

By feeding the training data into the neural network, a model can be produced
that can be used to predict future data. You can check the accuracy of the model
by using the test data.
